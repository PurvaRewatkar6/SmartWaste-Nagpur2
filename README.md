# 🚛 SmartWaste Nagpur

### Smart Garbage Collection & Citizen Tracking Prototype

SmartWaste Nagpur is a prototype designed to improve urban waste collection by connecting **citizens, garbage collection vehicles, workers, and municipal monitoring** through a single dashboard.

The project focuses on making garbage collection more **visible, organized, route-aware, and citizen-friendly**.

---

## 🎯 Problem Statement

Traditional garbage collection systems can face problems such as:

- Citizens not knowing when the garbage vehicle will arrive
- Inefficient or unclear collection routes
- Missed household pickups
- Lack of real-time collection status
- Difficulty for municipal authorities to monitor collection activity
- Unnecessary vehicle movement and delays

SmartWaste Nagpur aims to provide a simple digital solution for these problems.

---

## 💡 Our Solution

SmartWaste Nagpur provides a prototype system where:

- 🚛 Garbage vehicles follow area-wise routes
- 📍 Citizens can monitor vehicle proximity
- 🗺️ Vehicles follow waypoint-based routes instead of a single straight path
- 🔔 Citizens receive an arrival status when the vehicle enters a defined proximity zone
- 🗑️ Garbage handover can be completed digitally
- ⚠️ Missed pickups can be automatically identified
- 👷 Workers can monitor collection readiness
- 🏢 Municipal/NMC monitoring can track collection activity
- ⚡ EV-related vehicle information can be displayed through the dashboard

---

## ✨ Key Features

### 👤 Citizen Module

- Vehicle proximity tracking
- Estimated arrival information
- 60-meter citizen arrival geofence
- Garbage handover/pickup interaction
- Pickup completion status
- Missed pickup handling

### 🚛 Vehicle & Route Simulation

- Area-wise route management
- Multiple route waypoints
- Turns and bends in simulated routes
- Smooth vehicle movement
- Short demo-friendly routes
- Dynamic distance updates

### 👷 Worker Module

- Collection stop status
- Worker readiness information
- Active collection monitoring

### 🏢 NMC / Admin Module

- Collection monitoring
- Area-wise status
- Vehicle/route visibility
- Collection progress

### ⚡ EV Support

The prototype also includes EV-related vehicle information to support the concept of cleaner and more sustainable waste collection.
